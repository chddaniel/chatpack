Chatpack is a project by **[DanielCH](https://github.com/chddaniel)** and
**[DavidCH](https://github.com/chhddavid)**, who own and maintain it.

## Who wrote what

**[Yeabsra Habtu](https://github.com/Yeabsra-Habtu)** is the principal author of
the library — the core engine and permission model, the HTTP handler, the storage
adapter contract and both its memory and Drizzle/Postgres implementations, the
real-time SSE transport and the ephemeral plugin trio (`typing()`, `presence()`,
`receipts()`), and the first-party browser client.

**[Ikem Peter](https://github.com/ikemHood)** builds Chatpack alongside him. Ikem
wrote the moderation suite (ADR 0021), the client's message search and its
invite, join-request and channel wrappers, the CLI refresh, and the demo-api
seed fixtures.

**[DavidCH](https://github.com/chhddavid)** contributes to the code as well as
co-owning the project.

None of this is a claim you have to take on trust — the
[contributor graph](https://github.com/chddaniel/chatpack/graphs/contributors)
and `git shortlog -sne` in a clone both show it directly.

## Citing Chatpack

The repository ships a
[`CITATION.cff`](https://github.com/chddaniel/chatpack/blob/main/CITATION.cff)
file, so GitHub renders a **"Cite this repository"** button in the sidebar that
produces APA and BibTeX for you. Its author list follows the usual convention of
crediting the people who wrote the software, in order of contribution.
